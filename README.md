# Hash Table

A Python implementation of a hash table data structure that stores key-value pairs efficiently using a hash function. This project demonstrates the fundamentals of hashing, collision handling, and fast data retrieval.

## Features

- Insert key-value pairs
- Retrieve values by key
- Update existing values
- Remove key-value pairs
- Handle hash collisions
- Efficient key lookup

## Technologies

- Python 3

## Skills Demonstrated

- Data Structures
- Hash Tables
- Hash Functions
- Collision Resolution
- Dictionaries and Key-Value Storage
- Algorithm Design
- Object-Oriented Programming (OOP)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/hash-table.git
```

Navigate to the project directory:

```bash
cd hash-table
```

Run the project:

```bash
python main.py
```

## Example

```python
hash_table = HashTable()

hash_table.set("name", "Alice")
hash_table.set("age", 25)

print(hash_table.get("name"))
print(hash_table.get("age"))

hash_table.remove("age")
```
